# Security Policy

## Reporting a vulnerability

This package proxies API requests to https://www.apier.no/api/mcp using an API key read from the `APIER_API_KEY` environment variable. If you discover a vulnerability — credential leakage, transport-level issue, supply-chain concern, or anything else — please report it privately:

- Email: security@apier.no
- Or via the responsible-disclosure page at https://apier.no/security

We aim to acknowledge reports within 72 hours.

## Scope

This repository covers the npm package `@apier-no/mcp`. For vulnerabilities in the underlying https://apier.no platform itself, use the same channels above.
